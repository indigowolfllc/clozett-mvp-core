# VideoCloset Autonomous Operating System (VOSE v1.0)

## 1. Project Concept
自律運営・保守・改善を行うAI SaaS。人間は「最終承認者」に限定。
整理・片付けのメタファー（クローゼット・棚）を用いたUI。

## 2. Core Features (The 10 Pillars)
1. 保存UI (Closet UI)
2. oEmbed連携 (自動プレビュー)
3. 広告AB切替 (収益最適化)
4. 保存率トリガー (優先表示)
5. Slack通知・ログ化
6. SNS自動投稿 (X/Instagram)
7. LPコピー自己進化
8. 初回オンボーディング
9. 異常復旧・安全装置
10. 自律運営ループ

## 3. Design Principle
- インテリア・ライフスタイル系 (Apple/無印良品参考)
- ベース：オフホワイト、ベージュ
